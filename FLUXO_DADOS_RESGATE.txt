7️⃣  CENÁRIOS COBERTOS
    ┌────────────────────────────────────────────────────────────┐
    │ ✅ App envia registro                                      │
    │    → SALVO em JSONL imediatamente                          │
    │                                                             │
    │ ✅ Supabase connection fails (network down)                │
    │    → JSONL preserva cópia, sync tenta depois               │
    │                                                             │
    │ ✅ Render server reinicia                                  │
    │    → JSONL persiste em volume                              │
    │    → Arquivo não é perdido                                 │
    │                                                             │
    │ ✅ Múltiplos registros chegam rápido                       │
    │    → Todos acumulam em JSONL                               │
    │    → Ordem preservada por timestamp de requisição          │
    │                                                             │
    │ ✅ Período de coleta termina                               │
    │    → /resgate_temporario/2026-05-06/ completo              │
    │    → Pronto para batch import pra Supabase/Archive         │
    │                                                             │
    └────────────────────────────────────────────────────────────┘

8️⃣  GARANTIA DE SEGURANÇA
    ┌──────────────────────────────────────────────────────────┐
    │ Nenhum registro será perdido porque:                     │
    │                                                           │
    │ 1. JSONL é escrito ANTES de Supabase                     │
    │    → Supabase falhar não afeta local                     │
    │                                                           │
    │ 2. Render volume persiste entre restarts                 │
    │    → Dados não ficam em memória                          │
    │                                                           │
    │ 3. Arquivo append-only                                   │
    │    → Não sobrescreve histórico                           │
    │    → Idempotente                                         │
    │                                                           │
    │ 4. Estrutura diária por data                             │
    │    → 366 pastas = 1 ano de dados                         │
    │    → Fácil fazer busca temporal                          │
    │                                                           │
    │ 5. Permissões de arquivo configuradas                    │
