# BPMN - ObservaATT

Arquivo principal:

- `observa-att-fluxo.bpmn`

Escopo do fluxo:

- Registro de sinistro
- Validação de payload
- Persistência local
- Sincronização com Supabase
- Fallback local em falha de sync
- Publicação SSE
- Geração de exportações

Ferramentas que podem abrir o BPMN:

- Camunda Modeler
- bpmn.io
- Bizagi Modeler
